# 해금 초견 프로 — HAEGEUM SIGHT-READING PRO

현대 창작국악 · 고난도 초견 챌린지. 기존 `winningiron/haegeum-lounge`와는 완전히 다른 스타일·기능의 제2 연습 사이트입니다. 기존 저장소는 건드리지 않았습니다.

## 콘셉트
- 모던 다크 스튜디오: 깊은 차콜/먹색 배경 + 금빛/옥색 포인트, 악보 본문은 미색/아이보리 종이 톤. 다크/라이트 전환 토글 지원.
- 태블릿·모바일 보면대 최적화: "집중 연습 뷰"에서 상단 툴바와 하단 30초 카운트다운 띠가 악보와 겹치지 않고, 악보가 남은 화면을 꽉 채웁니다.
- 해금 합주 기준에 맞춰 기준음은 A4=442Hz가 기본입니다(440~450Hz 선택).

## 악보 (시범 12곡)
- 모든 악보는 **Verovio 6.4.1 + Leland 폰트**로 렌더링했습니다. 직접 도형 그리기는 쓰지 않았습니다.
- A4 세로 1페이지, PNG + PDF + MusicXML (`scores/001~012.*`).
- 사보 검증 규칙: ① 빔 중간 시작 슬러 금지 ② 쉼표 가로지르는 슬러 금지 ③ 시김새 겹침 0건 ④ 박자/조바꿈 줄 끝 예고표 ⑤ 번호 박스 + 우상단 `LEE SEUNG CHUL (with AI)` / 하단 `무단 복제 및 배포를 절대 금합니다.`
- 검증 결과는 `scores/validation.json`을 보세요. 빌드 스크립트는 `tools/build_scores.py`입니다.
- 조표 분포: E♭·A♭ 중심, B♭·D♭·G♭ 단계별 배치. 5/8·7/8 혼합박자, 조바꿈, 넓은 도약, subito p·cresc. 대비가 돋보이는 오리지널 연습곡입니다.

## 오디오 · 실전 연습 (Web Audio, 모두 동작)
- **곡별 타임라인**: 모든 곡에 MusicXML(`scores/*.musicxml`)과 재생 타임라인(`scores/*.timeline.json`, 음높이·음가·템포 변화·박자 변화·메트로놈 클릭·예비박 포함)이 함께 저장되어 있습니다. 생성기: `tools/make_timeline.py` (MusicXML → 타임라인 변환, 장식음 제외·타이 합침, 점4분음표 템포 보정 포함).
- **피아노 가이드 멜로디 재생**: 타임라인을 그대로 읽어 피아노 톤(Web Audio, 배음 합성)으로 재생. 템포 변화(예: 84→96→100)와 박자 변화를 그대로 반영하고, 속도 조절(0.75x / 0.85x / 1.0x) 및 현재 연주 중인 마디 번호 표시를 지원합니다.
- **예비박(카운트인) + 메트로놈 결합 재생**: 바로 시작하지 않고 첫 마디 박자만큼(5/8이면 5박, 4/4면 4박, 6/8이면 점4분음표 2박) "강-약-약..." 예비박을 먼저 친 뒤 본곡 시작. 3가지 모드: [피아노 + 메트로놈] / [예비박 + 메트로놈만 (피아노 OFF)] / [피아노만].
- **어려운 마디 구간 반복 (A-B 루프)**: 시작 마디~끝 마디(예: 15~22마디)를 지정해 느린 템포(0.75x 등)로 무한 반복 연습합니다. 구간 시작 마디의 박자·템포로 예비박을 다시 계산합니다.
- **해금 조율 기준음 A4=442Hz (440~450Hz 선택)**: 해금 기준음은 A4=442Hz를 기본값으로 두고, 440~450Hz를 1Hz 단위로 고를 수 있습니다. 기준음 재생과 곡의 으뜸음(E♭4 등) 주파수, 가이드 재생 피아노 음높이가 선택한 조율에 맞춰 비례 계산됩니다(예: A4=442Hz에서 E♭4=312.5Hz). 첫 음 미리 듣기 버튼도 같은 조율을 따릅니다.

## 기능 (모두 동작)
1. **30초 읽기 → 시작하세요!**: 곡을 열고 [30초 읽기]를 누르거나 집중 연습 뷰에 들어가면 화면 안 카운트다운이 30초를 세고, 끝나면 맑은 3음 차임과 함께 [시작하세요!]가 표시됩니다.
2. **내장 메트로놈 & 기준음**: Web Audio로 구현. 곡 템포가 자동 세팅되고, 첫 박 강조음이 있습니다. 기준음 A4=442Hz(440~450Hz 선택) 및 곡 으뜸음(E♭/A♭ 등) 재생 버튼.
3. **오늘의 모의고사**: 기초·중급·고급에서 랜덤 3곡을 묶어 연속으로 풉니다.
4. **진도 체크 & 개인 메모**: 완료 체크, 연습 횟수, 어려웠던 마디 메모를 localStorage에 자동 저장합니다.
5. **태그 기반 필터**: 난이도 외에 조표(E♭/A♭/B♭/D♭/G♭), 박자(5/8, 7/8, 4/4, 변박, 조바꿈) 필터링.
6. **곡 카드 악보 썸네일**: 첫 화면 카드마다 해당 곡 악보 상단을 은은한 미니 썸네일로 보여줍니다.
7. **집중 연습 뷰**: 상단바·하단 카운트다운 띠가 악보 영역과 겹치지 않게 세로 공간을 나눠 악보 첫 단부터 끝단까지 잘리지 않고 한 화면에 들어옵니다. 오디오 설정은 [오디오 설정] 버튼으로 접고 펼칩니다.

## 2단계 개선 (2026-11-28)
- **마디 하이라이트 + A-B 클릭 지정**: `tools/svg/*.svg`에서 마디 박스를 추출한 `measure-boxes/*.json`(PNG 분수 좌표)을 PNG 위에 div로 덧씌운다. SVG 직접 표시 대신 검증된 PNG + 좌표 오버레이를 택했다(헤더가 SVG에 없고 브라우저별 SVG 렌더 차이를 피하기 위해). 박스 정렬은 PNG 오버레이 이미지로 눈으로 검증했다. 재생 중 현재 마디 금색 하이라이트 + 따라가기 토글, 악보 클릭(시작)→Shift+클릭/다시 클릭(끝)으로 A-B 지정, loopA/loopB와 동기화.
- **속도 0.5x~1.1x 슬라이더 + ±5% 버튼 + Speed Trainer**(루프마다 +2%/+5%, 상한 1.1x, 메트로놈·가이드 모두 적용).
- **A-B 루프**: 숫자 입력만으로 반복 자동 활성화, "5–8마디 반복 중" 상태 표시.
- **필터 칩 동적 수집**: 조표·박자 칩을 pieces.json 태그에서 생성(3/4, 6/8, 9/8, 12/8 포함), "전체 12곡 중 N곡" 표시. 난이도 칩은 고정.
- **오늘의 모의고사**: YYYY-MM-DD 시드(같은 날짜 같은 3곡) + 완료곡 제외/연습 적은 곡 우선/난이도 선택 옵션 + 소요 시간·자가평가(상·중·하) 요약 화면.
- **진도 관리**: JSON 내보내기/가져오기(병합·덮어쓰기, 형식 검증·오류 안내), 최근 7일 연습량 SVG 그래프(날짜 없는 기존 기록은 제외하고 횟수만 안내), 되돌리기/전체 초기화. 연습 횟수에 날짜(`days`)를 함께 기록한다.
- **상단 접기/펼치기, Wake Lock(미지원 시 무시), 악보 줌 100%~200%, 단축키**(Space/M/←→, 입력창에서는 무시), aria-label 보강.
- **집중 뷰**: 가로 너비 맞춤 확대 + 단 단위 스크롤/마디 따라가기. 30초 타이머가 이미 돌고 있으면 재시작하지 않도록 수정. 일반 뷰 악보 폭 최대 1100px.
- **URL 해시 `#song-N`**, 테마·필터·속도(`hspro-speed`)·메트로놈(`hspro-metro`) 상태 유지. 필터 저장 키는 기존에 없어 `hspro-filters`를 새로 만들었다.
- **문구/버튼 정리**: "예비박 N박", 재생/정지 버튼 통합(정지 버튼 제거), 목록 썸네일은 첫 단 1~3마디 크롭(`scores/thumbs/`, 2마디는 정보 부족·4마디 이상은 너무 작아서 3마디 선택), 9번 카드 부제는 2줄로 분리. **피아노 음색**: 배음 합성 고도화(1~6배음 가중·감쇠, 미세 디튠, 저역통과 필터, 어택 8ms).
- 검증: `node --check app.js` 통과, jsdom 테스트 52개 + 트레이너 통합 테스트 7개 통과 (`/tmp/hspro-test/`는 임시 하네스, 저장소 밖). 실기기(폰·태블릿)에서의 눈·귀 확인은 아직이다.

## 3단계 개선 (2026-11-28)
- **강세 그룹핑 표기 (15)**: 곡 상세에 grouping을 표기한다 ("5/8 = 3+2", "7/8 = 3+2+2", pieces.json/timeline.json의 grouping 필드 사용). 메트로놈 3단계 피치는 이미 있던 값 그대로 쓴다 (마디 첫 박 1500Hz · 그룹 첫 박 1200Hz · 약박 1000Hz, `clickAt`). 단독 메트로놈과 가이드 재생 클릭이 `buildClickSchedule()`을 공유하므로 피치가 일치한다. 7/8 기본값도 실측값 3+2+2로 맞췄다.
- **개방현 조율 (16)**: 기준음·으뜸음 패널에 중현·유현·순차(중현→유현)·동시 버튼 추가. 김성아 《창작을 위한 국악기 이해와 활용》 6장 기준: 중현·유현 개방현은 조에 따라 달라지며, 기본 조율(E♭ 기준)에서는 중현 A♭3, 유현 E♭4로 둔다 (이 음정은 단정하지 않음 — 코드 주석에 근거를 남겼다). 계산은 중현 = 으뜸음보다 완전5도 아래, 유현 = 으뜸음과 같은 음 (`openStringsFor`, G♭곡 중현은 이론상 C♭4). 주파수는 A4 설정값(440~450Hz)에 비례해 이동한다.
- **메모 마디 태그 (17)**: 메모에서 "N마디" 패턴을 칩으로 뽑아 메모 아래에 보여준다. 칩을 누르면 그 마디 하나만 A-B 루프로 지정하고 재생 준비 상태로 만든다 (자동 재생은 안 한다). 자유 텍스트 메모는 그대로 유지한다.
- **마이크 피치 체크 (18)**: ON/OFF 토글, 켤 때만 `getUserMedia`를 요청한다 (페이지 로드 시 자동 요청 없음). AnalyserNode + 자기상관(autocorrelation)으로 추정하고, 음이름 + A4 설정값 기준 cent 차이를 표시한다. YIN은 넣지 않았다 — 차분 함수 + 임계값 탐색이 무겁고 단음 연습에는 자기상관으로 충분하기 때문이다. 권한 거부 시 안내 문구를 보여준다.
- **캐시 버스팅·PWA (19)**: `pieces.json`에 `version: 3` 추가 (`{"version": 3, "pieces": [...]}`), PNG/PDF/timeline/measure-boxes/썸네일 URL에 `?v=3`을 붙인다. `manifest.json` + `sw.js`(악보·껍데기 캐시, 오프라인 열람) + 아이콘(`icons/icon-192/512.png`) 추가. Service Worker 등록 실패 시에도 사이트가 정상 동작한다.
- **XSS 방지·CSP (20)**: `renderList()`와 모의고사 요약 화면의 innerHTML 문자열 조립을 `createElement`/`textContent`로 바꿨다 (썸네일 `onerror` 인라인 속성도 제거). 메모는 textarea 값으로만 다뤄 표시부에 innerHTML로 넣지 않는다. CSP meta 추가 (`default-src 'self'` 등). 인라인 스크립트·외부 리소스가 없어 기존 기능이 깨지지 않는다.
- **저작권 (21)**: MusicXML 다운로드 버튼 제거 (파일 12개는 타임라인 생성 원본으로 서버에 유지). PNG/PDF 12곡 전부 다시 렌더링하면서 PIL 폰트 렌더링으로 희미한 대각선 워터마크("해금 초견 프로 · 개인 연습 전용 / 무단 복제 금지", alpha 20)를 덧씌웠다 — 9번 PNG를 눈으로 확인했고 악보를 가리지 않는다. 악보 이미지에는 `user-select: none`, `-webkit-user-drag: none`, 우클릭·드래그 방지를 적용했다. 푸터·악보 하단에 "개인 연습 전용 · PDF만 제공" 라이선스 문구를 명확히 했다. 블라인드 모드는 넣지 않았다.
- 검증: `node --check app.js`·`sw.js` 통과, jsdom 스텁 테스트 45개 통과 (`/tmp/hspro-test/test-stage3.js`, 로컬 서버 8125). 실제 브라우저 스크린샷·오디오 청취·마이크 실제 입력·SW 오프라인 동작은 2단계와 마찬가지로 확인하지 못했다.

## GitHub Pages 배포 방법
이 VM의 `gh`는 로그인되어 있지 않아 저장소를 자동 생성할 수 없었습니다. 아래 중 하나로 배포하세요.

**방법 A — GitHub 웹사이트에서 직접 만들기 (권장)**
1. github.com → New repository → 이름 `haegeum-sightreading-pro` (Public) → Create
2. 이 폴더 내용을 업로드하거나, 로컬에서:
```bash
cd haegeum-sightreading-pro
git init
git add .
git commit -m "해금 초견 프로 시범 12곡"
git branch -M main
git remote add origin https://github.com/winningiron/haegeum-sightreading-pro.git
git push -u origin main
```
3. 저장소 Settings → Pages → Source를 `Deploy from a branch`, Branch `main` / `/ (root)`로 설정 → 저장
4. 배포 링크: https://winningiron.github.io/haegeum-sightreading-pro/

**방법 B — gh CLI로 만들기**
```bash
gh auth login
gh repo create winningiron/haegeum-sightreading-pro --public --source=. --push
# 이후 위 방법 A의 3번과 같이 Pages를 켜세요.
```
